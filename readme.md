# Lumina Creative

A clean, lightweight HTML/CSS website template for a creative agency.

## Overview

Lumina Creative is a small, responsive static site that showcases a creative agency's portfolio and services. It uses semantic HTML and a single CSS stylesheet to remain fast and easy to customize.

## Features

- Lightweight, dependency-free static site
- Responsive layout suitable for portfolio and agency pages
- Minimal CSS architecture for easy customization

## Getting Started

1. Open `index.html` in your browser to preview locally.

2. To serve locally with a simple HTTP server (recommended):

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

## Development

- Edit HTML files (`index.html`, `about.html`, `contact.html`) to update content.
- Modify styles in `css/style.css` to change layout, colors, and typography.

## Project Structure

- `index.html` — Home / landing page
- `about.html` — Agency/about page
- `contact.html` — Contact form or details
- `css/style.css` — Main stylesheet
- `images/` — Project images and assets
